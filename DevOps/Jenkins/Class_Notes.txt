	- Build Orchestration using Jenkins: 
	
	
	-> CI/CD Process :
	
		Automate Application Builds and Deployments :::
		
	- Jenkins - Build Orchestration Tool :::
	
		- Is an open-source build orchestration Tool 
		- Used to Create the end-to-end CICD Pipeline to automation application builds and deployments
		- Used to perform any scheduled process automation 
		
	
	
	
	- Jenkins Architecture :: CI & CD 
	
		- Jenkins is based on master/Controller & slave/Node
		
			- Jenkins Master/Controller (VM) :		
								- Install Jenkins 
								- To Create Jenkins Jobs/Projects/Pipelines and scheduled to run on the Jenkins Slave Nodes 
		
				- Jenkins Slave_Node (VM) (Build Server):	
								- Install the Build Tools 
								- To Execute the Jobs  

	
	
	
	Scenario 1: Application Build and Release Frequency is very less 
	
	
		- Create Jenkins Master/Controller (VM) :
				--> Install Jenkins 
				--> Install all the required Build Tools 
				--> Create Jenkins CI/CD Pipeline Projects & Execute the Build in same Jenkins_Master Node.	
			
			
			
			
	Scenario 2: Multiple Application Build and Release Frequency is very high 	


		- Jenkins Master/Controller (VM) :
				--> Install Jenkins 
				---> To Create Jenkins Jobs/Projects/Pipelines and scheduled to run on the Jenkins Slave Nodes 
			
		
			- Jenkins Slave_Node/Build_Server1  (VM):	Perform Java Application Build 
			- Jenkins Slave_Node/Build_Server1.1  (VM):	Perform Java Application Build 
			- Jenkins Slave_Node/Build_Server2  (VM):	Perform .Net Application Build 
			- Jenkins Slave_Node/Build_Server3  (VM):	Perform Python Application Build 
			- Jenkins Slave_Node/Build_Server4  (VM):	Perform Node Application Build 
			- Jenkins Slave_Node/Build_Server5  (VM):	Perform Angular Application Build 
			
			
	- Jenkins Pipelines/Jobs/Projects Workflow :
		
				- Application Build 
					==> Process of Compiling the Source Code, 
						Create the Artifacts(Executable code - Binaries - *.war/*.jar/*.exec/*.dll) 
				- Unit Test 
				- Promote the Changes to Test Environments
				- Notify the Testing Team thru Emails				
			
			
			
	CI/CD Workflow :::
	
		SCM_Checkout
