	- Build Orchestration using Jenkins: 
	
	
	-> CI/CD Process :
	
		Automate Application Builds and Deployments :::
		
	- Jenkins - Build Orchestration Tool :::
	
		- Is an open-source build orchestration Tool 
		- Used to Create the end-to-end CICD Pipeline to automation application builds and deployments
		- Used to perform any scheduled process automation 
		
	
	
	
	- Jenkins Architecture :: CI & CD 
	
		- Jenkins is based on master/Controller & slave/Node
		
			- Jenkins Master/Controller (VM) :		
								- Install Jenkins 
								- To Create Jenkins Jobs/Projects/Pipelines and scheduled to run on the Jenkins Slave Nodes 
		
				- Jenkins Slave_Node (VM) (Build Server):	
								- Install the Build Tools 
								- To Execute the Jobs  

	
	
	
	Scenario 1: Application Build and Release Frequency is very less 
	
	
		- Create Jenkins Master/Controller (VM) :
				--> Install Jenkins 
				--> Install all the required Build Tools 
				--> Create Jenkins CI/CD Pipeline Projects & Execute the Build in same Jenkins_Master Node.	
			
			
			
			
	Scenario 2: Multiple Application Build and Release Frequency is very high

		Jenkins Projects :
		
			- Jenkins Free Style Projects	::: Based on the Manual Configurations 
			
			- Jenkins Pipeline Projects 	::: Based on the Automation Script
												- Used to Onboard Applications to use DevOps CICD Process 
												
					
		Variables/Parameters  :::			
			
			- Environment Variables :		
			
				- Jenkins pre-defined variables/keywords 
				
				
				echo "Hello" 				# Print the constant value 

				
				echo "${var1}"				# Print the value of variable
				
				echo "jenkins-${JOB_NAME}-${BUILD_NUMBER}"
			
			
			
			- User Defined Varibles :		echo "User Defined Variables -${envi}"
			
			
			- Jenkins Pipeline Projects 	::: Based on the Automation Script
												- Used to Onboard Applications to use DevOps CICD Process 
												
												
		
			- Jenkins Pipeline are the collections of Stages 
			
				- Scripted Pipelines :::
				
				- Declarative Pipelines :::  yaml scripts key:value
				
					
			
			
				Pipeline 
					- Stage1 
						- step1 		# Task  
					- Stage2
						- step1 		# Task  		
					- Stage3
						- step1 		# Task 			
				
			
pipeline {
    agent any

    stages {
        stage('Hello') {
            steps {
                echo 'Hello World'
                echo 'Hello Everyone'
            }
        }
        stage('Hello1') {
            steps {
                echo 'Hello'
            }
        }
    }
}

pipeline {
    agent any

    stages {
        stage('SCM_Checkout') {
            steps {
                echo 'Perform SCM Check out'		
                echo 'Perform SCM Check out'					
            }
        }
        stage('Application Build') {
            steps {
                echo 'Perform Application Build'
            }
        }
        stage('Deploy to QA') {
            steps {
                echo 'Perform QA Deployment'
            }
        }
        stage('Deploy to UAT') {
            steps {
                echo 'Perform UAT Deployment'
            }
        }
        stage('Deploy to PROD') {
            steps {
                echo 'Perform PROD Deployment'
            }
        }
    }
}

pipeline {
    agent { label 'slave1' }

    stages {
        stage('SCM_Checkout') {
            steps {
                echo 'Perform SCM Check out'
				git 'https://github.com/PL-DevOps-Cloud-0930/java-webapp-project.git'				
            }
        }
        stage('Application Build') {
            steps {
                echo 'Perform Application Build'
            }
        }
        stage('Deploy to Target Server') {
            steps {
                echo 'Perform QA Deployment'
            }
        }
    }
}
